# Authorship and AI assistance

This project was completed by Javor Mirchev as ThinkCyber coursework.

- The laboratory environment runs locally on the author's computer.
- The author carried out the laboratory tests and captured the screenshots.
- AI tools assisted with coding and, in some cases, with report wording and descriptions of tests.
- The author prepared the project reports using the observed laboratory results, with AI assistance where applicable.

The portfolio preparation adds documentation, source packaging and automated checks. These checks do not replace the original laboratory tests. A historical report is evidence of the reported run; it is not a claim that every current environment or tool version has been tested.
